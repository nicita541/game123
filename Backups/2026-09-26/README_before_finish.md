# Эрудиция — Криптограмма

Мобильный вертикальный UI-прототип игры, собранный в Unity без пользовательских C#-скриптов. Вся визуальная структура и интерактивные переходы находятся в одной сцене и доступны через Hierarchy/Inspector.

## Открытие

1. Установите Unity 6.3 LTS (`6000.3.8f1` или совместимую версию) через Unity Hub.
2. Добавьте папку проекта `F:\game` в Unity Hub.
3. Откройте `Assets/Scenes/MainScene.unity`.
4. В Game View выберите портретное разрешение `1080 × 2340`.
5. Нажмите Play.

## Что готово

- 12 контейнеров `Screen_*` в одной сцене.
- Главное меню, выбор режима, Классика, Турбо, победа, отсутствие перьев, статистика, коллекции, достижения, магазин, настройки и Debug Panel.
- Canvas Scaler: `Scale With Screen Size`, reference resolution `1080 × 2340`, match `0.5`.
- Статическая Safe Area с безопасными отступами.
- 5 сердец в Классике и 3 сердца в Турбо.
- Русская клавиатура: каждая клавиша — отдельный GameObject.
- Пример no-code взаимодействия: правильные клавиши раскрывают заранее размещённые буквы; тестовые ошибочные клавиши гасят сердца.
- Переход на экран победы по кнопке `ПРОВЕРИТЬ`.
- Fake rewarded ad: показывает бонус после победы и меняет `0/5` на `1/5` на экране перьев.
- Нижняя навигация и экранные переходы через сериализованные `Button.onClick → GameObject.SetActive`.
- Debug Panel для перехода к любому важному состоянию.
- Фон и сова находятся в отдельных Sprite/Image-компонентах; UI не запечён в один скриншот.

## Дополнительные спрайты

Три PNG-листа уже настроены как **Multiple Sprites** в Unity и содержат 15 отдельных спрайтов:

- `authors_missing.png` — верхний ряд: Пушкин, Толстой, Достоевский; нижний ряд: Чехов, Гоголь, Тургенев.
- `collections_missing.png` — верхний ряд: Природа, Любовь, Мудрость; нижний ряд: Поэзия, Романы, Сказки.
- `owl_states_missing.png` — слева направо: Победа, Нет перьев, Магазин.

Исходный предоставленный лист сохранён отдельно в `Assets/ReferenceOnly/sprite_sheet_user_reference.png`; у него нет настоящего прозрачного фона. Три новых листа имеют альфа-канал и разделены на спрайты через импортные настройки Unity. Иллюстрации не содержат подписей: названия остаются редактируемыми текстовыми объектами сцены.

Каждый текст, индикатор, карточка, кнопка, сердце, клавиша и декоративный блок можно выбрать в Hierarchy и изменить через Inspector. Пользовательских компонентов и файлов `.cs` в проекте нет.

## Быстрая проверка

- Главное меню → `Классика` или `Турбо`.
- В Классике нажмите `А` или `О`, чтобы раскрыть буквы; `Й`, `Ц`, `У`, `Ф`, `Ы` гасят сердца.
- В Турбо нажмите `Л`; `Й`, `Ц`, `У` гасят сердца.
- `ПРОВЕРИТЬ` открывает победу.
- На победе кнопка рекламы показывает дополнительную награду.
- Настройки → `Открыть Debug Panel` даёт быстрый доступ ко всем экранам.

## Ограничение no-code версии

Сохранения, реальный таймер восстановления, автоматическая проверка произвольных криптограмм, магазинные транзакции и рекламный SDK требуют логического слоя. В текущей версии они представлены как полностью редактируемые демонстрационные состояния сцены и no-code переходы, чтобы соблюсти требование «без кода, всё на сцене».
