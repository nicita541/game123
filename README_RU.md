# Криптограммы: Шифры совы

Название для публикации обновлено; разработчик — Никита Цурбан. Комплект для Huawei AppGallery (Россия): [Publishing/HuaweiAppGallery/START_HERE.md](Publishing/HuaweiAppGallery/START_HERE.md). В нём графика, тексты карточки, инструкция и список оставшихся условий релиза. Архивные APK ниже ещё имеют прежнее название и тестовую подпись.

Играбельная мобильная игра для Unity 6.3 LTS (6000.3.8f1). Оформление основано на PNG-референсах в корне проекта и правилах из `prompt_cryptogram_unity_ru.txt`.

## Запуск

1. Откройте проект `F:\game` в Unity.
2. Откройте `Assets/Scenes/MainScene.unity`. Если сцена уже была открыта до обновления, переоткройте её с диска.
3. Выберите портретный Game View 1080 × 2340 и нажмите Play.
4. Выберите «Классика», нажмите на подчёркнутую ячейку, затем на букву экранной клавиатуры.

Не требуется запускать генератор, установщик или скрипт построения интерфейса.

## APK для Android

Для самостоятельной сборки сохраните сцены, закройте проект в Unity и дважды нажмите `Build-Android.cmd` в корне проекта. Скрипт сам найдёт нужную версию Unity и соберёт текущий проект. Последнее число версии повышается автоматически (`0.1.2 → 0.1.3`), первые два берутся из Player Settings; Bundle Version Code тоже увеличивается на 1. Новые значения сохраняются после успешной сборки. Готовый APK появится в `Builds/Android`, журнал — в `Builds/Android/Logs`. Каждый запуск создаёт отдельный файл с датой и временем. Подробности и проверка настройки без сборки: `Docs/BUILD_SCRIPT.md`.

Версия с исправлениями — 0.1.5. APK: `Builds/Android/Erudition-0.1.5-arm64.apk`; результаты проверки: `Builds/Android/BUILD-0.1.5.md`. Для 64-битных телефонов с Android 8.0 и новее; тестовая подпись, не ключ публикации в магазине. Запуск на физическом телефоне не проверялся.

## Всё находится в двух сценах

`MainScene.unity` содержит меню, подробности коллекции, победу, отсутствие перьев, статистику, коллекции, достижения, магазин, настройки, Debug Panel и поражение. `GameplayScene.unity` содержит Классику. Вторая сцена загружается аддитивно, без сборки интерфейса кодом. `GameplaySceneLink` связывает готовые объекты двух сцен. Турбо, его игровая доска и кнопки удалены. Старую незавершённую попытку можно продолжить в Классике без повторной оплаты.

Кнопки, подписи, иконки, картинки, панели, 33 клавиши и 480 ячеек — реальные GameObject с RectTransform, Image/Text/Button. Их положение, размер, цвет, шрифт и спрайт доступны в Inspector. Для просмотра экрана в Edit Mode выключите текущий `Screen_*` и включите нужный. Для совместного редактирования откройте GameplayScene аддитивно рядом с MainScene. В массиве `CryptogramGame.screens` место 2 назначает мост второй сцены; место 3 зарезервировано и пусто после удаления Турбо.

В `Assets/Prefabs` лежат 16 редактируемых образцов, включая LetterCell с подсветкой, KeyboardKey с зачёркиванием, CollectionDetails с прокруткой и SettingsScreen. У копий интерактивных префабов нужно назначать владельца/ссылки через Inspector; действующие сцены уже подключены.

Коллекции теперь создаются из `Assets/Data/CollectionCatalog.asset`: название, Sprite и список фраз. В сцене оставлена одна видимая карточка `CollectionCard_Template`; в игре она копируется и заполняется автоматически, сетка и прокрутка подстраиваются под количество. Остальные экраны сохранены в сценах. Инструкция по добавлению — [Docs/ADDING_CONTENT.md](Docs/ADDING_CONTENT.md). В `GameSystems` находятся контроллер игры, каталог, сохранения, реклама и аудио; одноразовые инструменты в `Tools/SceneAuthoring` для обычной работы не нужны.

По уточнению пользователя сова и окружающий декор объединены с библиотекой в цельные фоны: девять иллюстраций в `Assets/Art/Backgrounds` используются на 11 экранах. На каждом есть готовый `Illustration_Background` с RawImage; отдельные совы удалены из сцен. Заголовки, числа, прогресс, клавиатура, карточки и кнопки остаются самостоятельными объектами. Основную иллюстрацию можно свободно двигать и масштабировать. Отдельная подложка `Background_EdgeExtension_AutoFit` заполняет только края экрана за ней. Компоновка статистики и коллекций приближена к референсам; настройки получили отдельные строки с рисованными иконками и переключателями.

Положение интерфейса теперь берётся из сцены и не заменяется фиксированными координатами при старте. Сохранены последние ручные правки главного меню. Магазин возвращён к прежней компоновке с двумя пачками рядом, кнопки игры/победы/поражения — к рисованному оформлению. Порядок редактирования и объяснение служебных контейнеров: `Docs/SCENE_EDITING.md`.

## Правила и работающие возможности

- Каталог `PuzzleGenerator.cs` + `StoryCatalog.cs` + `VarietyCatalog.cs`: 5364 стабильные записи, включая 60 новых самостоятельных текстов — пословицы, загадки с ответами и размышления. Сложность, тип и текст выбираются случайно из доступных, включая более лёгкие задания. Последние 10 начатых текстов исключаются; история сохраняется. Явный повтор проигранной задачи — намеренное исключение.
- Новая игра начинается с 0 эрудиции и 0 монет. В новых заданиях заранее открыто максимум 5 букв на первых ступенях, 4 на средних и 3 на последней — даже в длинной фразе. Подсказки распределены по тексту и не раскрывают слово целиком. Уже начатые попытки сохраняют прежнее заполнение. Актуальные изменения — `Docs/NEXT_CELL_AUDIO_ADS.md`.
- Одинаковый шифр означает одинаковую букву. Ответ открывает только выбранную клетку: повторения нужно расставлять самостоятельно. Часть букв открыта заранее.
- Полный русский алфавит, включая Ё и Ъ. Повтор того же ошибочного ответа не снимает ещё одно сердце.
- Найденная буква остаётся зелёной и доступной, пока в тексте есть её незаполненные клетки. Когда все повторения расставлены, клавиша становится серой, зачёркивается и отключается. Выбранное место подсвечивается золотым, тот же шифр в других местах — голубым. Заполненные клетки, найденные буквы и выделение сохраняются при продолжении игры.
- Длинные задания и собранные истории прокручиваются. После правильного ответа и подсказки выделение переходит к следующей скрытой клетке, а не к началу текста. Свиток прокручивается только при необходимости; размер букв не уменьшается из-за длины текста.
- Классика: 3 сердечка. Третья ошибка завершает попытку. Это единственный режим для новых уровней.
- Новая попытка расходует 1 перо при старте; победа и поражение ничего дополнительно не списывают. Продолжение незавершённого уровня бесплатно.
- Запас энергии восстанавливается по одному перу за 20 минут, включая время вне игры. Максимум восстанавливаемой энергии — 5.
- Пачки оплачиваются игровыми монетами. Общий баланс перьев не ограничен: 90 сохраняются как 90. До пяти работает восстановление, от пяти и выше оно остановлено. Старый резерв переносится в общий баланс без потерь.
- Подсказка открывает только выбранную клетку. Победа начисляет эрудицию с учётом сложности, подсказок, ошибок и активного времени: лёгкое задание на лёгком уровне даёт 5–10, на среднем — 2–5. Монеты остаются +30. Расчёт показан на экране победы; подробности — `Docs/PUZZLE_VARIETY.md`.
- Если подсказок нет, открывается окно покупки 5 штук за 150 монет или получения 1 за полное рекламное видео. После пополнения одна подсказка сразу применяется к выбранной клетке; уровень и перья сохраняются.
- Сложность выбирается автоматически по эрудиции. После поражения доступна повторная попытка за перо; неразгаданные фраза и автор не показываются. Полный текст появляется после победы.
- Статистика, коллекции авторов/тем/книг, достижения и их вкладки обновляются по прохождению. Во вкладке коллекций «Типы» добавлены четыре карточки с фонами: цитаты и мысли, истории, пословицы, загадки; стрелка открывает собранные тексты.
- Стрелки коллекций открывают карточку с прогрессом и прочитанными цитатами; стрелки достижений — пояснение условия.
- В статистике работают периоды «Неделя», «Месяц» (последние 28 дней группами по четыре дня), «Год» (12 месяцев). История активности сохраняется.
- Кнопка «Мне нравится» удалена. Семь достижений учитывают решения, уровень эрудиции, Классику, собранные истории, точность и вечернюю серию.
- Сохраняются энергия и её таймер, прогресс уровня, валюта, подсказки, эрудиция, статистика, коллекции и настройки.
- Настройки управляют музыкой, звуками, вибрацией и размером текста. В `Assets/Audio` — записанное фортепиано Robin Alciatore / Musopen и Foley Kenney, без генерации ИИ; источники в `Assets/Audio/CREDITS.txt`.
- Safe Area адаптируется к экрану. Canvas Scaler использует 1080 × 2340; ориентация Portrait, Input Handling — Both.

## Реклама и особые товары

Официальный Yandex Mobile Ads Unity SDK 8.2.0 подключён для Android. Каждое поражение сразу запрашивает межстраничную рекламу без счётчика побед и ограничения по времени. После побед по-прежнему действует случайный интервал 2–4 победы и пауза 90 секунд. Недоступная реклама не блокирует игру, поздняя загрузка не прерывает следующий уровень. Видео за перо и подсказку требует события OnRewarded. Пока используются тестовые блоки `demo-interstitial-yandex` и `demo-rewarded-yandex`; для публикации нужны собственные ID. В обычном Editor успешный просмотр не имитируется.

Денежные платежи не подключены; недоступная секция особых товаров убрана. SDK использует собственный невидимый диспетчер, но не создаёт игрового интерфейса. Настройка и ограничения проверки — `Docs/FEEDBACK_2026-09-27.md`.
