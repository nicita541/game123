Как опубликовать «Криптограммы: Шифры совы» в Huawei AppGallery

Для Никиты Цурбана · Россия · русский язык · Android. Дата подготовки: 28.09.2026.

1. Зарегистрируйте разработчика

Откройте HUAWEI Developers и войдите с HUAWEI ID. Пройдите регистрацию и проверку личности как индивидуальный разработчик, если публикуете от своего имени. Укажите страну и реальные данные согласно документам. Имя для подготовленных материалов — Никита Цурбан, поддержка — prostosite42@gmail.com. Если кабинет требует полное имя с отчеством или другое написание по документам, приведите к нему и политику.

Документы для проверки личности передавайте только через официальный кабинет Huawei. Их состав и доступные варианты проверки определяет кабинет вашего аккаунта. Почта Gmail для поддержки сама по себе не является препятствием.

2. Создайте карточку Android-игры

Откройте AppGallery Connect. В списке приложений создайте приложение. Названия пунктов могут быть «Мои приложения», «Apps and atomic services» или «New app» в зависимости от интерфейса.

Не выбирайте HarmonyOS 5+, Quick App или Quick Game для существующего APK. Это отдельные способы разработки и публикации. Не включайте материковый Китай в этот выпуск.

Название в карточке должно совпасть с новым Product Name в Unity. Старый package name можно оставить: он технический, сохраняет идентичность приложения и не обязан совпадать с названием игры. Не меняйте его между обновлениями.

Для обычной публикации без сервисов Huawei можно создать приложение без привязки к проекту: это прямо предусмотрено процессом AppGallery Connect. Наличие рекламы Yandex само по себе не означает, что необходимо подключать Huawei Ads или авторизацию Huawei. Совместимость рекламы нужно проверить на устройстве.

3. Подготовьте политику конфиденциальности

Откройте privacy/PRIVACY_REVIEW.md, проверьте реальные настройки SDK и отредактируйте privacy/PRIVACY_POLICY_DRAFT_RU.md. Черновик уже содержит ваше имя, название игры и email, но не является подтверждением всех потоков данных в финальном APK.

После проверки:

  1. Разместите текст на общедоступной странице HTTPS без регистрации и пароля. Подойдёт ваш сайт или доступный вам статический хостинг.
  2. Откройте страницу на телефоне через мобильный интернет и в приватном режиме браузера.
  3. Вставьте полный HTTPS-адрес в поле политики в AppGallery Connect. Локальный файл, F:\..., email и ссылка на закрытый документ не подходят.
  4. Добавьте постоянную ссылку на эту страницу в настройки игры. Сейчас такой ссылки в проекте не обнаружено.
  5. Проверьте уведомление пользователя о данных и необходимых согласиях до соответствующей обработки. SetUserConsent(false) не заменяет политику и не означает отсутствие сетевой передачи данных.

HTML-версия в комплекте — удобный черновик для просмотра, с явной пометкой. Перед публичным размещением синхронизируйте исправленный текст и снимите пометку только после проверки.

4. Замените тестовую рекламу

В кабинете Рекламной сети Яндекса зарегистрируйте Android-приложение и получите собственные ID для rewarded и interstitial. В Unity откройте Assets/Scenes/MainScene.unity, найдите компонент AdsBridge у игрового системного объекта и замените:

  • Rewarded Ad Unit Id: вместо demo-rewarded-yandex — ID вашего блока с вознаграждением;
  • Interstitial Ad Unit Id: вместо demo-interstitial-yandex — ID вашего межстраничного блока.

Сохраните сцену. Значения сериализованы в сцене: замены строк по умолчанию только в Assets/Scripts/AdsBridge.cs недостаточно.

Проверьте рекламу официальными тестовыми средствами SDK, не нажимайте свои реальные объявления. На Huawei без Google-сервисов убедитесь, что загрузка, закрытие, отсутствие объявления и выдача награды работают. После закрытия видео до награды ресурс не должен начисляться. Не ставьте SetUserConsent(true) автоматически ради рекламы.

5. Назначьте иконку и соберите релиз

Для загрузки в магазин не используйте обычный Build-Android.cmd: его сборщик включает тестовую подпись. Смена пароля/ключа в Player Settings не исправит поведение этого сценария. Выполните сборку непосредственно через Unity.

  1. Откройте основной проект F:\game в Unity 6000.3.8f1.
  2. Скопируйте icons/app-icon-1024.png из этого комплекта в новую папку Assets/Art/AppGallery. В Player Settings → Icon назначьте его как Default Icon и проверьте Android Legacy/Round. Для Adaptive Icon используйте того же персонажа с безопасными отступами и отдельный непрозрачный фон; проверьте круглую и квадратную маски. У карточки магазина и установленной игры должен быть один узнаваемый значок.
  3. В Player Settings проверьте Company Name: Никита Цурбан, Product Name: Криптограммы: Шифры совы. Эти два значения уже изменены в файлах проекта.
  4. В Android → Other Settings проверьте Package Name com.owlberrystudio.erudition, Minimum API Level 26, IL2CPP, ARM64. Установите поддерживаемый Huawei целевой API; прежний APK имеет targetSdk 36. Не копируйте требования Google Play в Huawei без проверки подсказки кабинета.
  5. Для первого магазинного выпуска можно поставить Version 1.0.0, Bundle Version Code 7. Это предложение: код должен быть больше всех ранее загруженных в эту карточку и уже выпущенных кодов. В текущем проекте — 0.1.5 / 6.
  6. Откройте Publishing Settings → Keystore Manager. Создайте свой постоянный release-keystore и ключ с длительным сроком действия. Включите Custom Keystore, выберите этот файл, alias и введите пароли. Если у вас уже есть ключ ранее опубликованной версии, используйте совместимый с выбранной схемой подписи ключ.
  7. Храните резервную копию keystore и паролей в надёжном отдельном месте. Не включайте их в архив материалов, Git или переписку. Для обычного APK можно использовать собственную подпись; если включаете App Signing Huawei, следуйте выбранной схеме signing key/upload key. Официальное описание.
  8. В Build Profiles выберите Android. Development Build, Script Debugging, Autoconnect Profiler — выключены. Для первого выпуска здесь предусмотрен APK; Build App Bundle и Export Project выключены.
  9. Проверьте список сцен: MainScene первой, GameplayScene второй. Нажмите Build и сохраните новый файл, например Builds/Android/OwlCiphers-1.0.0-release.apk.
  10. Проверьте APK, затем установите именно этот файл на Huawei. После окончательных правок исходников пересобирайте APK и обновляйте версию/код по необходимости.

При смене подписи Android не установит релиз поверх APK с прежним тестовым ключом. Для тестового устройства заранее учитывайте потерю локального прогресса при очистке данных или удалении старой установки. Не удаляйте игру автоматически у пользователей.

Команды проверки в PowerShell с установленными здесь Android Build Tools:

$apkPath = 'F:\game\Builds\Android\OwlCiphers-1.0.0-release.apk'
$androidTools = 'D:\uni\uniti\6000.3.8f1\Editor\Data\PlaybackEngines\AndroidPlayer\SDK\build-tools\36.0.0'
& "$androidTools\aapt.exe" dump badging $apkPath
& "$androidTools\aapt.exe" dump permissions $apkPath
& "$androidTools\apksigner.bat" verify --verbose --print-certs $apkPath
& "$androidTools\zipalign.exe" -c -P 16 4 $apkPath
Get-FileHash -LiteralPath $apkPath -Algorithm SHA256

Если apksigner.bat не находит Java, задайте для текущего терминала JAVA_HOME на D:\uni\uniti\6000.3.8f1\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK. На другом компьютере пути будут другими. Нужны успешная проверка подписи, сертификат вашего релизного ключа вместо Android Debug, правильные package name и версии. SHA-256 — контрольная сумма файла, а не сертификата. Успешный zipalign не заменяет проверку запуска и всех библиотек.

Начните с icons/app-icon-216.png; если поле просит другое разрешение, рядом есть 512 и 1024 px. Затем загрузите четыре файла из screenshots/ в порядке 01, 02, 03, 05. Это полные снимки игры 1080 × 2340, JPEG, без дополнительного оформления. Исходники без JPEG-сжатия находятся в screenshots_original/. Перед отправкой сравните изображения с финальным APK.

Точные ограничения именно Android-полей проверьте в текущем кабинете: общедоступная таблица Huawei, которую удалось прочитать, относится к HarmonyOS 5+, и её нельзя автоматически считать требованиями к Android. Все размеры и назначение подготовленных файлов зафиксированы в ASSETS.md. Не растягивайте снимок 1080 × 2340 до 1080 × 1920: это исказит интерфейс.

promo/banner-1920x1080.jpg используйте только там, где запрашивается подходящий дополнительный промоматериал, либо для публикации в соцсетях. Баннер и контактный лист не загружайте вместо скриншотов интерфейса.

7. Заполните возрастной рейтинг и сведения о данных

Заполните анкету в кабинете по реальному содержимому всех текстов игры и показываемой рекламе. Не указывайте произвольное «0+» или «для детей»: возрастной рейтинг пока не определён. В текущем SDK отдельно не установлен детский режим; реклама должна соответствовать выбранной аудитории.

Подтверждено по игровому коду: нет чата, пользовательских публикаций, регистрации, денежных покупок и азартных ставок. Есть рекламные ролики, локальные сохранения и внутриигровые ресурсы. При этом весь каталог цитат/историй и фактические объявления ещё нужно проверить на темы, влияющие на рейтинг. Данные рекламных библиотек указывайте с учётом TECHNICAL_AUDIT.md и privacy/PRIVACY_REVIEW.md.

Проверьте права на тексты, переводы, портреты, иллюстрации, музыку и шрифты. В проекте есть лицензии аудио и шрифта Inter, но это не доказывает права на каждый остальной материал. Сохраните документы и источники, если кабинет запросит подтверждение.

8. Протестируйте и отправьте

Пройдите RELEASE_CHECKLIST.md именно на окончательном подписанном APK. Загрузите этот APK в раздел версии приложения, дождитесь обработки пакета. Проверьте распознанные название, иконку, идентификатор, версию и поддерживаемые устройства.

Добавьте URL политики, рейтинг, сведения о рекламе и данные поддержки. Страны — Россия. Откройте предпросмотр карточки, сравните скриншоты с финальной игрой. Вставляйте reviewer-notes.txt только после подтверждения описанного поведения; тестовый аккаунт не требуется.

Когда обязательные поля и проверки завершены, отправьте на модерацию. Срок и результат заранее не гарантируются. Если Huawei вернёт замечания, исправляйте конкретную причину; при изменении APK увеличивайте versionCode и подписывайте ключом, совместимым с первой публикацией.

После выхода

Установите игру из AppGallery на отдельное тестовое устройство, проверьте запуск, значок, рекламу и страницу политики. Сохраните отправленный APK, хеш, версию и резервную копию ключа. Для обновлений сохраняйте package name и схему подписи, увеличивайте versionCode и меняйте «Что нового» на реальные изменения.
