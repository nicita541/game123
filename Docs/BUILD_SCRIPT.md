# Сборка APK одним запуском

1. Сохраните изменения в Unity, включая сцены: **Ctrl+S**.
2. Закройте проект в Unity. Unity Hub закрывать не нужно.
3. В папке проекта дважды нажмите **Build-Android.cmd**.
4. Дождитесь надписи **BUILD SUCCEEDED**. Окно останется открытым и покажет путь к APK.

Результат: `Builds/Android/Erudition-<версия>-<дата-время>-arm64.apk`.
Журнал: `Builds/Android/Logs/Erudition-<версия>-<дата-время>-arm64.log`.
Рядом с APK сохраняется контрольная сумма SHA-256. Предыдущие APK не перезаписываются.

Собираются сохранённые файлы **основного проекта**, включая все включённые сцены из Build Settings. Скрипт не копирует игру из `_feedback_validation`; из этой папки используется только кеш Gradle, если он уже существует. При его отсутствии кеш создаётся в `Builds/Android/GradleCache`.

## Что нужно установить один раз

В Unity Hub нужна версия из `ProjectSettings/ProjectVersion.txt` (сейчас **6000.3.8f1**) с модулями:

- Android Build Support;
- Android SDK & NDK Tools;
- OpenJDK.

Эти компоненты уже найдены на этом компьютере. Unity должна быть активирована и хотя бы один раз нормально открывать проект. При первом запуске или появлении новых зависимостей может понадобиться интернет. Ничего дополнительно устанавливать скрипт не пытается.

## Параметры сборки

APK для Android ARM64, IL2CPP, без Development Build, с обычной тестовой подписью Android. Это вариант для установки и проверки на телефоне. Для публикации в магазине нужен отдельный процесс подписи вашим ключом.

Название приложения, идентификатор и минимальная версия Android берутся из Player Settings.

**Версия повышается автоматически:** `0.1.2 → 0.1.3 → 0.1.4`. Первые два числа берутся из **Player Settings → Android → Other Settings → Identification → Version** без изменений. Если вручную поставить `0.2.0`, следующий APK получит `0.2.1`. Version должна состоять из трёх чисел через точку.

**Bundle Version Code тоже увеличивается на 1** от значения в Player Settings. Новые значения записываются в APK и сохраняются в проекте после успешной сборки. При обычной ошибке сборки старые значения восстанавливаются; `-CheckOnly` только показывает будущую версию и ничего не меняет. Имя APK содержит новую версию.

Если на телефоне стоит архивный APK 0.1.5 с versionCode 6, а в проекте код ниже 6, один раз установите Bundle Version Code не меньше 6: следующая сборка получит код 7 или выше. Скрипт считает от настроек проекта, а не от архивных APK. Подпись должна совпадать с уже установленной игрой.

Настройки ARM64/IL2CPP, тестовой подписи и формата APK выставляются на время сборки и восстанавливаются при её завершении, в том числе при обычной ошибке. Активной платформой проекта после запуска будет Android.

## Проверка и ручной запуск

Из PowerShell в папке проекта — проверить Unity, Android-модули и показать следующую версию, без запуска сборки и изменения настроек:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Build-Android.ps1 -CheckOnly
```

Обычная сборка из PowerShell, без паузы в конце:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Build-Android.ps1
```

Если редактор установлен в нестандартном месте и Unity Hub его не находит:

```powershell
.\Build-Android.cmd -UnityPath "D:\uni\uniti\6000.3.8f1\Editor\Unity.exe"
```

Можно также задать переменную `UNITY_EDITOR_PATH`. Редактор другой версии скрипт не запустит.

## Если появилась ошибка

- **Save your scenes and close this project** — сохраните сцены и закройте Unity, затем повторите запуск.
- **Android component is missing** — добавьте указанные Android-модули через Unity Hub.
- **Input Manager (Old)** — в Player Settings выберите Active Input Handling → Input Manager (Old), перезапустите редактор, сохраните и закройте проект. Текущие настройки уже соответствуют этому требованию.
- **BUILD FAILED** — в окне указан журнал сборки и показаны его последние строки. Полный журнал содержит точную ошибку Unity, C# или Gradle.
- Если проект перенесён в папку с кириллицей, укажите кеш Gradle без кириллицы: `Build-Android.cmd -GradleCachePath "F:\UnityGradleCache"`. Это устраняет ранее встречавшуюся ошибку Gradle/Prefab с путём профиля пользователя.

`ExecutionPolicy Bypass` действует только для запущенного процесса PowerShell; системная политика и системные переменные окружения не меняются.
