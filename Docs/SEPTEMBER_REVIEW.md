# Правки по четырём замечаниям — 27 сентября 2026

- Поражение: неразгаданные фраза и автор очищаются и скрываются в сцене и при каждом открытии экрана. Карточка уменьшена до сообщения поддержки. Повтор того же задания стоит одно перо; при победе полный текст показывается.
- Коллекции: портреты и их широкие подложки ограничены масками карточек и области портрета, добавлен внутренний отступ. Исправлены сохранённая сцена и образцы AuthorCard/CollectionCard. Проверены обычный экран, 16:9, экран с вырезом, прокрутка и крупный текст.
- Турбо: обе кнопки и игровая доска удалены из сцен; остались 480 клеток и 33 клавиши Классики. Значения enum и старые записи каталога сохранены ради совместимости индексов. Начатая в прежней версии попытка Турбо продолжается на оставшейся доске с прежними открытыми клетками и сердцами, без повторного списания пера. Новые уровни выбираются только из Классики.
- Стартовые буквы: целевой объём 20%, 18%, 16%, 14%, 12% по ступеням эрудиции. Буквы распределяются по всей фразе с предпочтением разных символов; целое слово заранее не открывается. Поэтому для необычного текста фактическое число подсказок может быть меньше целевого. Правильный ответ и подсказка открывают ровно выбранную клетку; одинаковые буквы нужно расставлять отдельно. Сохранённые попытки не меняются.

## Файлы и восстановление

Исходное состояние перед этой правкой: `Backups/before-september-review` (сцены, скрипты, префабы). До переноса проверенных сцен их контрольные суммы сравнивались с резервной копией, чтобы не затереть параллельное редактирование.

Авторинг сохранённых объектов выполнен `Tools/SceneAuthoring/SeptemberFeedbackPass.cs` в `_feedback_validation`. Это одноразовая миграция из резервного состояния, повторно поверх готовых сцен её запускать не нужно. Игровой код не перестраивает интерфейс.

Для повторной проверки скопировать текущие Assets в отдельный проект, а в его Assets/Editor — `SeptemberFeedbackTests.cs`. Старые инструменты UsabilityTests/SceneLayoutOwnership относятся к версии с двумя режимами и для актуального проекта не используются. Точка входа Unity: `-batchmode -executeMethod SeptemberFeedbackTests.Run`, без `-quit`. Тест использует отдельный ключ сохранений, прогресс игрока не затрагивает.
