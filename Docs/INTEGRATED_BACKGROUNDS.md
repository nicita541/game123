# Цельные фоны по референсам

По уточнению пользователя сова, книги и окружающий декор являются одной фоновой иллюстрацией. Поверх фона остаётся настоящий редактируемый интерфейс Unity. Ни один сгенерированный фон не содержит чисел, клавиатуры, рабочих кнопок или игрового текста.

Использован навык imagegen и встроенный инструмент редактирования изображений, не CLI. Девять финальных PNG находятся в `F:/game/Assets/Art/Backgrounds`. Исходные референсы сохранены без изменений. Отдельный пробный спрайт совы не используется.
