# Обновление 0.1.5 — ввод, стартовые буквы, реклама, меню и звук

## Итоговые изменения

- После правильного ответа или подсказки выбирается ближайшая следующая скрытая клетка. Пропускаются пробелы, знаки препинания и заполненные клетки. К началу фразы игра возвращается только после последней скрытой клетки. Положение и заполнение сохраняются при продолжении.
- Стартовые подсказки ограничены по ступеням эрудиции: максимум 5, 5, 4, 4, 3 клетки. Длина фразы больше не увеличивает число открытых букв без ограничения. Подсказки по-прежнему распределены по тексту и не раскрывают слово целиком. В уже начатых попытках сохраняется прежнее заполнение.
- Кнопка рекламы за бонус после победы удалена вместе с начислением этого бонуса. Обычная награда остаётся +20 эрудиции, +30 монет, +1 в коллекцию. Значение старого действия в enum зарезервировано, чтобы не сдвигать действия всех сохранённых кнопок.
- Межстраничная реклама автоматически вызывается на экране победы после случайного интервала в 2–4 победы, не чаще одного раза за 90 секунд. Перед показом есть 0,8 секунды для появления результата. Уход с экрана отменяет показ; загрузка в фоне сама ничего не показывает. Если объявления нет, результат и дальнейшая игра доступны сразу. Счётчик и время последнего показа сохраняются. Вознаграждаемое видео для восстановления пера сохранено.
- По последнему уточнению пользователя возвращено исходное зелёное оформление «Классики», включая размеры, книгу, подпись и стрелку. Изменено только положение кнопки: Y = −540 в сохранённой сцене.
- Синтезированные тоны заменены существующими записями: музыка — полный фортепианный трек Эрика Сати «Гимнопедия №1» в исполнении Robin Alciatore, Musopen, 183,59 с; эффекты — Foley из Kenney RPG Audio (2014): страница книги, металлический щелчок, закрывание книги и монеты. Громкость сведена, музыка плавно начинается и заканчивается. Музыка импортируется потоком, переключатель продолжает её с места паузы. Источники и условия: `Assets/Audio/CREDITS.txt`; авторы указаны в настройках игры.

## Проверка

В Unity прошли базовые игровые регрессии и `NextCellRegression`: ответ в нижней части длинного текста не прыгает вверх, подсказка двигает выделение вперёд, переход через конец, сохранение выделения, лимиты подсказок для 2–480 букв, удаление бонусной кнопки, отсутствие лишнего начисления, наличие записанных аудиоклипов. Сценарии рекламы проверены с явно включённым тестовым обработчиком: автоматический вызов, интервал, пауза 90 секунд, сохранение, повторное событие победы, отсутствие объявления, поздняя загрузка, уход в меню и начало следующего уровня. Обычный Editor не имитирует рекламный показ.

Маркеры: `NEXT_CELL_AND_AUDIO_PASS`, `INTERSTITIAL_POLICY_PASS`, `SEPTEMBER_RUNTIME_PASS`. Журнал: `Docs/ValidationLogs/next-cell-tests.log`. Снимки: `Review/NextCellReview` (включая 16:9 и экран с вырезом). В редакторе остаётся ранее наблюдавшееся исключение индексации UnityEditor.Search, не связанное с игровым кодом; игровые проверки завершились успешно.

Подключён официальный Android API Yandex Mobile Ads 8.2.0. Межстраничный блок пока `demo-interstitial-yandex`, видео за перо — `demo-rewarded-yandex`. Для публикации нужны собственные ID. Настоящий показ SDK и звучание через динамики физического телефона пока не проверялись.

Резервная копия до обновления: `Backups/before-next-cell-ads`. Сцена изменялась и проверялась в `_feedback_validation`, затем перенесена в основной проект после сверки контрольной суммы исходной сцены. Для восстановления зелёной кнопки использована копия исходной сцены `RestoreReference_Main.unity` только в тестовом проекте. В сборку входят MainScene и GameplayScene.

Для повторных тестов поместить `SeptemberFeedbackTests.cs` и `NextCellRegression.cs` в Assets/Editor отдельной копии и вызвать `NextCellRegression.Run` без `-quit`. Авторинг `NextCellFeedbackPass` для обычного запуска игры не нужен.
